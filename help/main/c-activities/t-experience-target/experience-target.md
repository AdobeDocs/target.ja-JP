# [!UICONTROL &#x200B; エクスペリエンスのターゲット設定]を開始する {#get-started-xt}

>[!BEGINSHADEBOX]

**このページ：**&#x200B;では、**[!UICONTROL エクスペリエンスのターゲット設定]**&#x200B;の概要、パーソナライゼーションへの取り組み、シナリオが異なるエクスペリエンスを持つ様々なオーディエンスをターゲットにする方法について説明します。

>[!ENDSHADEBOX]

[!UICONTROL &#x200B; エクスペリエンスのターゲット設定] （XT）は、マーケターが定義した一連のルールと条件に基づいて、特定のオーディエンスにコンテンツを配信します。 特定のエクスペリエンスまたはコンテンツを特定のオーディエンスにターゲットするルール（[地域ターゲット設定](/help/main/c-target/c-audiences/c-target-rules/geo.md)）を定義する場合に役立ちます。 複数のルールを単一のアクティビティで定義して、様々なコンテンツバリエーションを様々なオーディエンスに配信できます。

訪問者がサイトを表示すると、[!UICONTROL &#x200B; エクスペリエンスのターゲット設定]は、それらの訪問者が設定した条件を満たしているかどうかを判断するために評価します。 条件を満たした場合は、アクティビティにエントリすると、適格なオーディエンス向けに設計されたエクスペリエンスが表示されます。

[!UICONTROL &#x200B; エクスペリエンスのターゲット設定]は、パーソナライゼーションの世界への第一歩であり、多くの場合、A/B テストから始まります。 マーケターはA/B テストを実施し、レポート用のオーディエンスを使用して、さまざまなエクスペリエンスがさまざまなオーディエンスの共感を呼ぶことを発見します。 [!UICONTROL &#x200B; エクスペリエンスのターゲット設定]を使用すると、マーケターはその検出を使用して、それらの異なるオーディエンスセグメントに対するコンテンツの長期的なターゲティングに切り替えることができます。

## シナリオ：A/B テストからエクスペリエンスのターゲティングへ {#xt-scenario}

例えば、自社のweb サイトに屋外機器が掲載されているとします。 A/B テスト用のレポートでは、3つのエクスペリエンスが異なるオーディエンスの共感を呼ぶことを示しています。 この発見を応用するには、訪問者の場所や趣味に応じて、ホームページに別のヒーロー画像を表示して、各オーディエンスにアピールします。 ニュージャージー州の訪問者にハイキング画像、ハワイの訪問者にサーフィン画像、自転車が好きなオーディエンスに3番目の画像を表示します。

「[!UICONTROL &#x200B; エクスペリエンスのターゲット設定]」アクティビティを使用すると、これらの3つのオーディエンスを、それぞれ異なるヒーローイメージでターゲット設定できます。 次のビデオでは、[!UICONTROL &#x200B; エクスペリエンスのターゲット設定]でA/B テストを次のレベルに引き上げる方法について説明します。 例えば、次のことが可能になります。

* 3段階のガイド付きワークフローを使用して、[!UICONTROL &#x200B; エクスペリエンスのターゲット設定] アクティビティを設定します。
* 両州をターゲットにした体験とバイク愛好家をターゲットにした3つ目の体験を構築することで、さまざまな地域のオーディエンスに位置情報に基づくコンテンツを提供します。
* 3つのエクスペリエンスを並べ替えて、適切なコンテンツが的確なオーディエンスに配信されるようにします。
