# Adobe Adobe Targetの共同作業スキル {#coworker-skills}

>[!BEGINSHADEBOX]

**このページでは、** アクティビティとオーディエンスの探索、テストの作成と設定、パフォーマンスの分析、オーディエンスの構成、レコメンデーションの管理など、Adobe Targetで利用できる共同作業スキルについて説明します。

>[!ENDSHADEBOX]

Adobe Targetの実務担当者は、共同作業に必要なスキルを磨き、自然言語を使用してテストやパーソナライゼーションプログラムを検討したり、アクティビティを作成および設定したり、結果を分析したり、配信の問題を解決したりできます。 Coworker Chatで何をしたいのかを説明し、返される推奨事項、設定、分析を確認してからアクションを実行します。

[!DNL Adobe Target]個のMCP ツールと共同作業者は別々に文書化され、異なる機能を提供します。

* [Target MCP](../c-integrating-target-with-mac/mcp/target-mcp-tools-reference.md)は、サポートされているアクティビティの種類、パラメーター、権限、読み取りまたは書き込みスコープなど、直接MCP サーバーによって公開される個々のツールを文書化します。
* [Coworker](https://experienceleague.adobe.com/ja/docs/cx-enterprise-ai/experience-cloud-ai/coworker/chat/use-cases/overview#target-activities-and-audiences)は、機能を組み合わせて追加のワークフローを適用できる、個別の自然言語オーケストレーションレイヤーを提供します。

次の表は、関連する機能の大まかな比較です。

| 機能 | ターゲット MCP | Coworker |
| --- | --- | --- |
| 実行中の実験、オーディエンス、オファー、最近変更された項目のリスト | ○ | ○ |
| Automated Personalization アクティビティの作成 | × | × |
| ターゲットオーディエンスの作成 | ○ | ○ |
| ターゲット VEC アクティビティ、エクスペリエンスのターゲット設定アクティビティ、またはA/B テストの作成 | ○ | ○ |
| Target Recommendations アクティビティの作成 | ○ | ○ |
| TargetでのHTMLまたはJSON オファーの作成 | ○ | ○ |
| Target アクティビティでのAEM コンテンツフラグメントの使用 | × | ○ |
| 何が機能して、次にテストすべきかをレコメンドします | いいえ、または一般的なアドバイス | はい |


## Target プラグイン

次のスキルは、**Target** プラグインで利用できます。

* **ターゲットブラウズ**

  アクティビティ、オーディエンス、オファー、関連する設定など、Target エンティティの読み取り専用の検出、検査、カウントを提供します。

>[!BEGINSHADEBOX]

*プロンプト例：*

* 「自分のアクティブなアクティビティを一覧表示します。」
* 「現在実行されているアクティビティの数はいくつですか？」
* 「このアクティビティで使用されるオーディエンスとオファーを表示する。」

>[!ENDSHADEBOX]

* **ターゲットアクティビティの評決**

  アクティビティの出荷準備が整っているか、追加のデータを待つか、停止するか、修正が必要かを、有意計算と設定チェックを使用して決定します。

>[!BEGINSHADEBOX]

*プロンプト例：*

* 「このテストは発送すべきですか？」
* 「この活動は停止する準備ができていますか？」
* 「現在のアクティビティ設定に問題はありますか？」

>[!ENDSHADEBOX]

* **ターゲットデザイン**

  アクティビティとオファーの作成と設定、QA URLの生成、オファーコンテンツの作成または最適化を行います。

>[!BEGINSHADEBOX]

*プロンプト例：*

* 「ホームページのA/B テストの作成」
* 「再訪問者体験のオファーを作成します。」
* 「このアクティビティのQA URLを生成します。」

>[!ENDSHADEBOX]

* **ターゲット VEC**

  Visual Experience Composer アクティビティとそのページ配信オーディエンスを作成および編集します。

>[!BEGINSHADEBOX]

*プロンプト例：*

* 「ホームページのVEC A/B テストを作成します。」
* 「VEC アクティビティでヒーローヘッドラインを編集します。」
* 「このVEC アクティビティのページ配信オーディエンスを作成します。」

>[!ENDSHADEBOX]

* **ターゲット設定**

  A/B テスト、エクスペリエンスのターゲット設定、前提条件、スケジュール設定、QA、アクティベーションなど、Adobe Experience Composerのアクティビティ制作を包括的にサポートします。

>[!BEGINSHADEBOX]

    *例のプロンプト：*
    
    * 「最初のテストの作成を手伝ってください」 
    *「エクスペリエンスのターゲット設定アクティビティを作成する前に必要なものは何ですか？」 
    *「このアクティビティのスケジュール、QA、アクティベートについて説明してください」 

>[!ENDSHADEBOX]

* **ターゲットインテリジェンス**

  監査プログラムをターゲットに、リスク、衝突、設定の誤り、衛生上の問題、短期間での成功を確認します。

>[!BEGINSHADEBOX]

*プロンプト例：*

* 「Target アクティビティを監査する」
* 「自分のアクティビティ全体で衝突または設定リスクを見つける」
* 「どのようなクイックウィンがTarget プログラムの健全性を向上させることができますか？」

>[!ENDSHADEBOX]

* **ターゲットストラテジスト**

  過去のTarget データを分析して勝利パターンを特定し、今後のテストを推奨します。

>[!BEGINSHADEBOX]

*プロンプト例：*

* 「過去の結果に基づいて次に何をテストすればよいか？」
* 「最もパフォーマンスの高いテストでは、どのようなパターンが表示されますか？」
* 「このアクティビティの結果に基づいてフォローアップテストを推奨します。」

>[!ENDSHADEBOX]

* **ターゲットテスト計算**

  複数の比較に対応するBonferroni補正により、コンバージョン指標と収益指標のA/B/n サンプルサイズ、期間、検出可能なリフトを計画します。

>[!BEGINSHADEBOX]

*プロンプト例：*

* 「必要なサンプルサイズは？」
* 「このA/B テストを実行して、5%の上昇率を検出するには、どのくらいの時間が必要ですか？」
* 「この交通量でどんな検出可能な上昇率を測れますか？」

>[!ENDSHADEBOX]

* **Target Portfolio レポート**

  プログラム全体の読み取り専用のパフォーマンスロールアップと、アクティビティの傾向およびモメンタム分析を提供します。

>[!BEGINSHADEBOX]

*プロンプト例：*

* 「一番上と最低のテストはどれですか？」
* 「アクティビティ全体のパフォーマンスの傾向を表示します。」
* 「最近、勢いを増した、あるいは失った活動はどれですか？」

>[!ENDSHADEBOX]

* **Target Audience Composer**

  自然言語の説明や明示的なルールをもとに、ターゲットネイティブのオーディエンスを作成および編集。

>[!BEGINSHADEBOX]

*プロンプト例：*

* 「モバイル訪問者をリピートするためのオーディエンスを作成する」
* 「このオーディエンスを編集して、オーガニック検索の訪問者を含めます。」
* 「価格ページを閲覧した訪問者に対してターゲットオーディエンスを作成します。」

>[!ENDSHADEBOX]

* **ターゲットのレコメンデーション**

  Target Recommendations アクティビティと設定を管理し、操作します。

>[!BEGINSHADEBOX]

*プロンプト例：*

* 「Recommendations アクティビティの作成」
* 「Recommendations アクティビティと設定を表示する」
* 「このRecommendations アクティビティの設定を更新します。」

>[!ENDSHADEBOX]

* **Target Recommendations Diagnose**

  Recommendationsの配信、設定、カタログ、フィードの問題を診断します。

>[!BEGINSHADEBOX]

*プロンプト例：*

* 「なぜおすすめの情報が表示されないのですか？」
* 「このRecommendations アクティビティのフィードとカタログ設定を診断します。」
* 「配信または設定の問題がレコメンデーションに影響を与えていますか？」

>[!ENDSHADEBOX]
